# Contributing to Aether

Read `AGENTS.md`, `README.md`, and `STATUS.md` before starting work. Take the smallest unblocked task, record its state, verify the change, and capture evidence before marking it done.

Run `npm run format:check`, `npm run lint`, `npm run test`, `npm run typecheck`, `npm run build`, and `npm run authorship:check` before proposing a change.

All repository work uses the local Git identity `Sreenath <sreenathmmmenon@gmail.com>`. Do not use attribution trailers or add generated-by notices. Follow the WebMCP safety, command-path, and human-approval boundaries in `AGENTS.md`.
